# 宅建 一問一答

宅地建物取引士試験の学習アプリ。動画（再生リスト順）→ 章 → 問題、という順で進める作りで、
復習は「学習済みの小分類から1問ずつの抜き打ち」を主役にしている。

**このリポジトリに入っているのは画面とロジックだけです。問題文・解説・図表は含まれていません。**

過去問の著作権は一般財団法人 不動産適正取引推進機構に、解説の著作権はその発行元に帰属します。
再配布はしないので、問題データはリポジトリに置かず、利用者が自分の端末に用意した
`takken_data.json` を読み込んで、その端末の中（IndexedDB）だけに保存します。

## 使い方

1. iPhone の Safari で公開ページを開く
2. **共有 → ホーム画面に追加**（タブのままだと7日で記録が消えます）
3. ホーム画面のアイコンから起動し、`takken_data.json` を選ぶ
4. 以後はオフラインで起動します

データを入れ直すときは、URL の末尾に `#import` を付けて開きます。

## 中身

| ファイル | 中身 |
|---|---|
| `index.html` | 画面（HTML/CSS）とデータ読み込み |
| `app.js` | 出題・復習・分析・演出のロジック |
| `sw.js` | オフライン起動用。**殻だけ**をキャッシュする |
| `manifest.webmanifest` | ホーム画面追加の設定 |

`index.html` と `app.js` は `tools/build_pwa.py`（このリポジトリの外）が `app.html` から生成します。
手で編集しても次のビルドで消えます。

## 記録

学習の記録は `localStorage`（キー `takken_v1`）に入ります。
アプリを更新しても消えません。端末をまたぐときは、アプリ内の書き出し／読み込みで移します。
